学习linux内核第一步：自己编译安装一轮linux内核。但是担心安装新内核系统崩了，所以需要准备好回复环境。


### 编译与安装内核

```bash
make oldconfig
make -j $(nproc)
sudo make modules_install
sudo make install
```
`make install`会自动完成安装内核的一系列操作，包括：
- 复制 vmlinuz 内核镜像到 /boot/
- 复制 System.map 文件到  boot/
- 使用 dracut 生成对应的 initramfs 文件
- 在 GRUB 配置中添加新内核的启动条目

此时直接重启，不出意外就能进入新内核

### 配置grub

使用grubby工具管理grub配置文件

```bash
sudo grubby --info=ALL
```
列出grub所有的内核条目

如果grub没有自动添加新内核，可以手动添加：
```bash
sudo grubby --add-kernel=/boot/vmlinuz-5.10.0-新版 \
  --title="linux 新版" \
  --initrd=/boot/initramfs-5.10.0-新版.img \
  --args="console=ttyAMA0,115200n8 console=tty0"
```

设置默认内核
```bash
sudo grubby --set-default=/boot/vmlinuz-5.10.0-旧版
```

确认引导的默认内核
```bash
grubby --default-kernel
```

仅在下一次启动设置默认内核
```bash
 sudo grub2-reboot "linux 新版"
```
此时只有下一次重启时grub默认会选择新版内核

可以修改 grub 的超时时间留给我们选择内核：
```bash
sudo vi /etc/default/grub
# 找到 GRUB_TIMEOUT 参数，修改为 10 秒
sudo update-grub
# 更新 grub 配置文件
```


准备好回退的内核，就可以 sudo reboot 重启系统了
进入 grub 后可以手动选择内核，或者超时后自动选择默认内核
